Manual setup: find the serial and address in the apps
First check account discovery
  1. Use the same international phone number and region as MyCentsys Remote.
  2. In MyCentsys Pro, connect to the operator, open Users, then select MyCentsys Remote. Confirm your number is listed and enabled. An Operator Admin entry alone is a separate role.
  3. In MyCentsys Remote, open SMART Settings → SMART Plus Retrieval, then retry Find account gates here. Retrieval may return nothing even when a manually added gate works. You do not need to delete it.
Copy the controller serial
  1. Open MyCentsys Pro near the gate, enable phone Bluetooth if needed, and connect to the operator.
  2. Open the operator's settings and find Operator Information.
  3. Find Serial Number and tap its copy icon. Paste the full 24-character value into Controller serial number below. Do not use the gate name, product model or IP address.
Copy the Wi-Fi MAC for the D5 Evo SMART+ helper
  1. In Pro, connect to the operator and open Wi-Fi Settings.
  2. Under Advanced Wi-Fi Information, find MAC Address. Copy the six byte pairs into Wi-Fi MAC from Pro below.
  3. Confirm your exact model in Operator Information is D5 Evo SMART+, then close Pro and Remote. Leave gate Wi-Fi enabled and connected to cloud.
  4. After updating this plugin, restart its child bridge before using the helper so setup and monitoring share the session lock.
  5. Click Verify Wi-Fi address below. On success the helper fills the protocol MAC. Review the gate and save.

The Wi-Fi MAC is not the protocol MAC. This experimental helper tries the single conversion observed on one D5 Evo SMART+ in South Africa. It must receive accepted identity authentication and fresh live status before applying the address. It sends no movement command and does not search other addresses if the check fails. Other controllers are not supported.

A timeout may mean the gate is still reconnecting, rather than an incorrect address. Wait and retry manually. If verification keeps failing, record the model, firmware and app versions for setup assistance. Share identifying screenshots privately, not in a public issue.

Use the Wi-Fi MAC from Pro (D5 Evo SMART+ only)

For South African D5 Evo SMART+ operators when discovery supplies no protocol address. Use the steps in Manual setup above.

Close Pro and Remote first. Verification can take up to 30 seconds. If another session is busy, retry when it finishes. Only a verified address is applied; saving remains a separate step.

Use the device address supplied by cloud discovery or independently validated for this controller. The Wi-Fi MAC shown in MyCentsys Pro can be different. This is required for live availability checks even when open/close control is disabled.

Open/close control (experimental)

Live monitoring requires the protocol address above and is supported for D5 Evo SMART+ in South Africa. Open/close control is optional; one complete physical HomeKit cycle has been confirmed on this profile.

The plugin will reject ambiguous positions and will not automatically repeat an activation whose outcome is unknown. A request may wait up to 30 seconds for fresh gate status before failing; movement can start after a delay. Apple Home reports an obstruction only when detected; missing or disabled beam feedback does not confirm that the driveway is clear.

Restart this plugin's child bridge, or Homebridge, after saving or changing accounts. Sign-in survives restarts and updates when Homebridge storage is persistent. Codes are never saved.
