2. Set up your gate

Gate not found? Get its details from MyCentsys Pro
  1. Connect to your gate in MyCentsys Pro using Bluetooth.
  2. Open Settings → Operator Information → Serial Number. Copy all 24 characters.
  3. Open Wi-Fi Settings → Advanced Wi-Fi Information → MAC Address. Copy it into Wi-Fi MAC from Pro below.

Use Pro for these details; MyCentsys Remote does not show them.

Paste Pro’s MAC here. Verify it to generate the different address Homebridge needs.

Close Pro and Remote. Keep the gate’s Wi-Fi connected.
